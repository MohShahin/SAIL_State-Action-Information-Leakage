Does the Severity Score Already Know the Treatment?

A methodological audit of SOFA-based state representations used in offline reinforcement learning for sepsis treatment, conducted on MIMIC-IV. This project spans a formal proof, an interactive walkthrough, a live mechanism visualizer, and a fully reproducible extraction pipeline — the four sections below are entry points into each.

Preliminary results — internal audit, independently re-verified. See Status & roadmap for the full provenance history.

The three claims, in one line each

H1 — proven
The SOFA score's own definition can't be recovered from blood pressure alone once a treatment threshold is crossed
H2 — proven
Aggregation windows overlap prior treatment — provably nonzero, with a corrected account of exactly how it scales
H3 — open
Whether the resulting predictability gap reflects genuine leakage or ordinary treatment persistence — being tested now

Extraction queries

Four standalone SQL files, safe to publish — code isn't data. See queries/README.md for the full run order and a substitution script that avoids the placeholder bugs this project hit early on.

queries/01_cohort.sqlSQL
-- adult, first-ICU-stay, Sepsis-3-qualifying, vasopressor-exposed stays
WITH ranked_icu AS (
  SELECT ie.subject_id, ie.hadm_id, ie.stay_id,
    ROW_NUMBER() OVER (PARTITION BY ie.subject_id ORDER BY ie.intime) AS rn
  FROM `physionet-data.mimiciv_3_1_icu.icustays` ie
  JOIN `physionet-data.mimiciv_3_1_hosp.patients` p USING(subject_id)
  WHERE p.anchor_age >= 18
)
SELECT f.* FROM ranked_icu f WHERE f.rn = 1;
-- verified: 11,354 stays, exact match across five independent runs
queries/03_vasopressor_doses.sql (excerpt)SQL
-- six vasopressor/inotrope agents; four are dose-scored by the 1996
-- Vincent cardiovascular SOFA rule (norepi, epi, dopamine, dobutamine)
SELECT ie.stay_id, ie.itemid, ie.starttime, ie.endtime, ie.rate, ie.amount
FROM `physionet-data.mimiciv_3_1_icu.inputevents` ie
JOIN `{SCRATCH_DATASET}.sepsis_cohort` c USING(stay_id)
WHERE ie.itemid IN (221906, 221289, 221662, 221653, 221749, 222315)
  AND ie.amount > 0 AND ie.endtime IS NOT NULL;

Data governance

MIMIC-IV requires PhysioNet credentialing. This repository publishes queries and aggregate-only results — never row-level or patient-level data, enforced by an explicit .gitignore policy, not just intention.

Safe to publish
SQL queries, analysis code, aggregate statistics reported in the manuscript
Never published
Any file with one row per patient or per decision-point — enforced by an explicit gitignore block, verified against full git history before every push
Full governance policy →

Getting your own access

  1. Complete CITI "Data or Specimens Only Research" training
  2. Apply for credentialed MIMIC-IV access via PhysioNet
  3. Request BigQuery access to the physionet-data project
  4. Run scripts/check_setup.sh to verify your environment before touching any query

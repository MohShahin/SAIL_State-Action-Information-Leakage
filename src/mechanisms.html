The two mechanisms

Both are provable — see the formal proof page for the full theorems. This page is the intuitive deep-dive: what each mechanism is, why it happens, and how much it actually measures out to.

Terminology: this is confounding, not ML-sense leakage

Both mechanisms below were originally described as "leakage." A reviewer correctly pushed back: A_(t-1) → S_t → A_t — prior treatment shaping the current state, which then informs the next decision — is ordinary sequential decision-making, not leakage. True leakage would be a state containing information about the same action epoch it's used to predict, or information not yet available at decision time. The two diagrams below are that distinction, made visual.

This isn't a retreat from the project's findings — it's a stronger, more precise claim. H1 and H2 are real, provable, and still a genuine problem for offline-RL state design (a state that's a near-deterministic function of the prior action still threatens the causal assumptions policy learning relies on) — they're just a different, causal-inference-flavored pathology (conditioning on a variable affected by treatment) than the ML-flavored "leakage" charge, and the fix is different too: disentangling the treatment-history term, not correcting an indexing bug. Full derivation: FORMAL_ANALYSIS.md §1.1.

One more distinction worth stating plainly: whether a given feature counts as "confounded for this task" is itself task-specific. A feature that's confounded for predicting the next action may be exactly the right feature for predicting mortality — mortality prediction doesn't carry the same "was this available before the decision" constraint action-prediction does.

Mechanism 1 — Treatment-confounded severity construction

The cardiovascular SOFA subscore is defined as a function of two things: mean arterial pressure, and whichever vasopressor drug and dose is currently running. Above a dose threshold, the scoring rule's branches stop referencing blood pressure entirely — two patients with opposite blood pressure, same dose, get the identical score.

Removing the subscore alone isn't sufficient: the overall SOFA total is a deterministic sum of all six organ subscores, so the cardiovascular contribution is exactly reconstructible from the total minus the other five — this is why variant C (subscore removed, total kept) barely drops in predictability (0.885 vs. 0.900), while variant D (total recomputed from a treatment-independent proxy) drops close to the floor set by the variant with no explicit treatment features (0.792 vs. 0.791).

$$\sigma_{cardio} = \text{sofa\_total} - \sum_{i \ne cardio}\text{subscore}_i$$

Full statement and proof: Theorem 1 and Theorem 2.

Mechanism 2 — Treatment overlap

A "current state" snapshot is built by aggregating physiology over a lookback window. If that window overlaps a period when treatment was already running, the snapshot carries treatment history into it — even with no drug-dose term in any scoring formula at all.

The counterintuitive part: a naive "wider window, more overlap" intuition is false in general. Absolute overlap hours are provably non-decreasing in window length (windows nest), but the fraction is a ratio of a growing numerator to a growing denominator — it rises exactly when marginal treatment density exceeds average density accumulated so far, the same relationship as a marginal-cost curve crossing an average-cost curve. This is why a 4-hour window measured a higher >50%-overlap rate than the 24-hour window in this project's own data.

Full statement and proof: Section 5, treatment overlap.

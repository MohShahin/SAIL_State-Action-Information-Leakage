Privacy

Both real, shipped pieces of SAIL run entirely on your machine. This page states exactly what that means today, and is explicit about the one thing that's designed but not built.

The sail-leakage package

The package reads the file (or DataFrame) you give it and returns a report. It makes no network requests, sends no telemetry, and has no server component — there is nothing in its dependency chain that talks to the network. Verifying this is as simple as reading its source; there are five detector modules and an orchestrator, nothing else.

The VS Code extension

The extension's setup wizard runs the installed sail-leakage package in a local Python subprocess on your own machine, the same way the package itself works from a terminal. The sidebar states this directly: "Runs on this computer. Your patient data is never uploaded." That line isn't marketing copy sitting next to the mechanism — it describes what the code actually does, which you can check in the extension's source.

What isn't built yet: AI-assistant fix suggestions

A future feature (an MCP server offering LLM-assisted fix suggestions inside the editor) is fully designed but not implemented — no server, no AI-assistant-facing code, and no network path for your data exist anywhere in the codebase today. The design commits to three tiers before a line of it is written: aggregate finding metadata sent by default, code snippets requiring a separate explicit opt-in plus a pre-send preview of the exact payload every time, and raw data values that are never transmissible by construction — not a setting that could be switched on. Any cloud API key it eventually uses would live in VS Code's SecretStorage (your OS keychain), never in a settings file, and a local-model option (e.g. Ollama) would sit alongside the cloud option so a network call is never required at all. The full spec, marked with its current "not started" status, is public.

This project's own data handling

The research behind SAIL was built on credentialed MIMIC-IV data under a PhysioNet Data Use Agreement, which restricts what can be published at row level. See DATA_ACCESS.md for exactly what that means and what this repository does and doesn't contain as a result.

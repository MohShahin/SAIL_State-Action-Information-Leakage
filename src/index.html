SAIL

We gave a model a question and accidentally also gave it the answer.

This is that story — and it's not about a bad model. It's about a widely-used clinical score that was never designed to be a machine-learning feature, and the open-source detector that catches it before it ships into one.

pip install sail-leakage

Also available as a VS Code extension (setup wizard, plain-language results, no Python typing required). It isn't on the Marketplace yet — build the .vsix from source: see the extension's README.

How it works

1

Pick your dataset

A CSV or Parquet file from your workspace, or try the example data first — no setup beyond having sail-leakage installed.

2

Confirm the columns

SAIL auto-detects the patient ID, time step, treatment and outcome fields from typical column names — you just confirm or correct them.

3

Read the report

Five checks, each explained in plain language: what it checks, what SAIL found, and what to do about it. Everything runs on your computer.

What it checks

Five categories, each a generalization of a mathematically proven mechanism from the underlying research — not a heuristic guess.

Construction leakage

Is a treatment dose built into one of the patient-state scores?

Reconstruction leakage

Can a hidden score be rebuilt from the scores the model can see?

Temporal overlap

Does the treatment period overlap the time window the state describes?

Timing violation

Is any state value measured after the treatment it should come before?

Persistence dominance

Would simply repeating the last treatment beat your model?

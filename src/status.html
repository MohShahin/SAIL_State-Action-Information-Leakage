What was found and fixed

Bug 1 — WRITE_APPEND
The cohort table's BigQuery load had no write_disposition set. A re-run against an already-populated table silently duplicated rows (~15x), inflating every downstream join. Confirmed twice: once by code inspection, once by recovering the original buggy Colab run and reproducing the exact inflated figures.
Bug 2 — schema autodetect
BigQuery's schema autodetection mapped timestamp columns to the wrong type, breaking joins against source tables. Fixed with an explicit schema.
Bug 3 — sum vs. union
The window-overlap calculation summed overlapping intervals instead of taking their union, double-counting patients on multiple simultaneous vasopressors (34.8% of the cohort). A smaller, present-day contributor alongside Bug 1.

Reviewer response — Mortality-predictive validity per variant (Experiment 6, 2026-09-03)

Operationalizes the clinical reviewer's task-specificity point: does a variant's lower action-recoverability also mean lower mortality-predictive validity? Action-recoverability gap (A minus E) = 0.109 — large. Mortality-AUROC gap (A minus E) = 0.011 — roughly a tenth the size. Reported as the actual result: sanitizing the state costs almost nothing in mortality-prediction accuracy despite costing a lot in next-action predictability. Full write-up: evidence page.

Done

Reviewer response — Respiratory SOFA, a second mechanism instance (Experiment 7 / Proposition 3, 2026-09-04)

Tests whether the cardiovascular non-identifiability pattern generalizes to a different SOFA subscore. It doesn't, in the same form — respiratory SOFA shows a narrower score-shift collision instead: for PF in [100,200), two patients with identical PF get different official scores (3 vs. 2) purely as a function of ventilation status. A genuinely different mathematical shape, deliberately isolated from Experiments 1/2/3/6. Full write-up: evidence page, proof: FORMAL_ANALYSIS.md §4.5.

Done

Reviewer response — Variant F disentanglement test (Experiment 8, 2026-09-08)

Tests a specific alternative to Variant D: keep severity untouched, add explicit treatment-history features (duration on vasopressor, time since last dose-tier change) alongside it. The pre-registered success criterion was falsified — F's action-recoverability AUROC (0.914) exceeded even the full state's (0.900), rather than staying near D's (0.792). Reported as the actual result: two purely temporal features are more predictive of the next action than the entire physiology-plus-severity state, sharpening the treatment-persistence account below rather than avoiding it. Full write-up: evidence page, proof: FORMAL_ANALYSIS.md §7.5.

Phase 4 — Experiment 5 (negative controls)

All four controls have run: shuffled labels (AUROC ≈0.5, as expected), a 5-offset temporal decay curve (0.874 at 0h down to 0.703 at 32h), a cross-reference against the variant with no explicit treatment features, and prevalence-matched placebo features (matches variant E's own number, confirming the placebo adds nothing). Results: notebook/results/experiment5_negative_controls.json. H3 itself is not yet resolved by this data: the pre-registered decision procedure is a paired cluster bootstrap on the AUROC(0)−AUROC(8) difference specifically — resampling patients once per iteration and computing both AUROCs on that same resample — not the marginal decay curve or a threshold on the point estimate, which this project's own analysis states is not a valid test since the two AUROCs share the same correlated patients. The run that produced the numbers above bootstrapped each offset independently and saved only the aggregate AUROC and CI per offset, discarding the individual per-patient predictions a joint/paired resample needs. This is a small, well-understood next step — save predictions across offsets, then one new paired-bootstrap analysis pass — not an open-ended gap. See the formal proof page's pre-registered decision rule.

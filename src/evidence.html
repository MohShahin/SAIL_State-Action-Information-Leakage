Why Experiment 2's gap is the strongest single result

The AUROC gap (0.900 → 0.791) survived a 15× difference in underlying vasopressor-dose row counts almost untouched — 0.109 verified vs. ≈0.108 in the original, inflated-data run. A result that's this stable despite a large upstream data bug is strong evidence it reflects something structural (Theorems 1–2), not an artifact of how the data was extracted.

The three bugs, found and fixed in the open

Bug 1 — WRITE_APPEND
The cohort table's BigQuery load had no write_disposition. A re-run against an already-populated table silently duplicated rows (~15x). Confirmed twice — by code inspection, and by recovering the original buggy Colab run and reproducing its exact inflated numbers.
Bug 2 — schema autodetect
BigQuery's schema autodetection mapped a timestamp column to the wrong type, breaking downstream joins. Fixed with an explicit schema.
Bug 3 — sum vs. union
The window-overlap calculation summed overlapping intervals instead of taking their union, double-counting patients on simultaneous multi-drug vasopressor therapy (34.8% of the cohort).

Full diagnostic trail — including the false starts — in ROADMAP.md.

What's still open

Experiment 5's negative-control battery (shuffled labels, a 5-offset temporal decay curve, physiology-only cross-reference, prevalence-matched placebo features) has not yet run — this is what resolves H3. See the pre-registered decision procedure and current status.
